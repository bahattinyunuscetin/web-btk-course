# HTML Course

Bu klasör, ~14 saatlik HTML kursu kapsamında oluşturulan projeleri ve kod örneklerini içerir.

## İçerik

*   **HTML Yapısı**: Temel etiketler ve sayfa iskeleti.
*   **Formlar ve Tablolar**: Veri girişi ve gösterimi.
*   **Semantik HTML**: SEO ve erişilebilirlik için doğru etiket kullanımı.
*   **Proje**: Kişisel web sitesi iskeleti (`personal-website`).
