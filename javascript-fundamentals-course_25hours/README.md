# JavaScript Fundamentals Course

Bu klasör, ~25 saatlik JavaScript Temelleri kursu kapsamında oluşturulan projeleri ve kod örneklerini içerir.

## İçerik

*   **Temel Sözdizimi**: Değişkenler, döngüler, koşullu ifadeler.
*   **Fonksiyonlar ve Scope**: Kod organizasyonu.
*   **DOM Manipülasyonu**: Sayfa elemanlarını dinamik olarak yönetme.
*   **Nesne Yönelimli Programlama (OOP)**: Sınıflar ve nesneler.
*   **Asenkron Programlama**: `Promise`, `async/await` yapıları.
*   **Örnekler**: Daire alanı hesaplama, form doğrulama, hata yönetimi vb.
