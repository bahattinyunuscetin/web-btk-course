# CSS Fundamentals Course

Bu klasör, ~10 saatlik CSS Temelleri kursu kapsamında oluşturulan projeleri ve kod örneklerini içerir.

## İçerik

*   **CSS Seçiciler ve Özellikler**: Temel stillendirme teknikleri.
*   **Layout Tasarımı**: Flexbox ve Grid sistemleri.
*   **Responsive Tasarım**: Farklı ekran boyutları için uyumlu tasarımlar.
*   **Proje**: Kişisel web sitesi tasarımı (`personal-website`).
